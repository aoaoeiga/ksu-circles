# デザイン改修 2026-09-29

この文書は、旧 Claude Design（`docs/ui/02-ui-spec.md`・`06-design-reference.md`）と `CLAUDE.md` に残っていたデザイン上の矛盾を置き換える、現行UIの判断記録。

## 方針

- 温かい白系の紙色、濃い文字、落ち着いた朱茶 `#984738` を基本にする。朱茶は選択・一致・主要導線に限り、意味のない装飾には使わない
- 英字の大見出しは使わず、日本語で目的が分かる見出しにする
- トップは複数の実在団体写真を組んだ編集的な表紙とし、その第一画面から検索・一覧へ進める
- 表紙の団体は `tile_size = L` とジャンルの多様さから決定論的に選ぶ。乱数を使わず、SSRとハイドレーションを一致させる
- 一覧は比較しやすい同寸の3:2カード。写真、団体名、キャッチコピー、活動日、活動場所、年会費の順で読む
- 詳細のヒーローはスマホ74svh、PC78svhを上限とし、次の判断情報を同じ画面内にのぞかせる。全画面固定・ズーム・stickyは使わない
- 一覧と詳細の写真は Framer Motion の `layoutId` でつなぐ。stickyを使わず、戻り時の復元スクロールとの座標衝突を避ける
- カルーセルはクロスフェードのみ。触ったら自動送りを止め、再開しない

## 表示と操作

- 検索対象は通称、正式名称、キャッチコピー、ジャンル、区分
- 既存の曜日・区分・ジャンル・年会費・初心者フィルターと、URL共有を維持する
- 絞り込みで全タイルを計測するFLIPは行わない。158件は通常DOMで描画し、画面外カードに `content-visibility: auto` を使う
- 長い団体名は一覧で2行まで。詳細では幅に応じて折り返す
- 写真なし・読み込み失敗は、従来どおりジャンル色＋頭文字へ落とす
- タップ中の写真はわずかに明るくし、pointer up/cancel/leaveで必ず通常値へ戻す
- 主要な操作は44px以上、フォーカスを可視化し、`prefers-reduced-motion` を尊重する

## 掲載内容

掲載15項目、未確認の表示、`¥0` と未確認の区別、団体ID URL、公開判定は変更しない。詳細は「写真と団体名 → キャッチコピー → 紹介文 → 活動情報 → 数字 → 代表の一言 → 参加・問い合わせ」の順にする。

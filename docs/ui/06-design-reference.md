## 4つに共通していたもの

バラバラに見えるが、共通の文法が4つある。**この4つが今のサークル名鑑に欠けていた。**

### 1. 大きな英字見出し ＋ 小さな和文アイバー

irodas は `Business` `Service` `Vision` を巨大に置き、その上に小さく「事業紹介」「提供しているサービス」を添える。GO も `ABOUT GO` を主役サイズで組み、上に「タクシーアプリ『GO』について」を細い罫線付きで置く。アイザックも「## ニュース / News」の二段。

**英字が見出しの役割を、和文が意味の役割を分担している。**和文だけで組むと、どうしても資料っぽくなる。

### 2. 和文ラベルの字間を極端に広く取る

irodas の本文と GO のアイバーは、和文の字間がはっきり広い。これが端正さの正体。

ただし**広げるのはラベルと短い行だけ。**本文まで広げると読みにくい。v3では ラベル 0.14em / 本文 0.02em に分けた。

### 3. 角丸の大きい面を、地から浮かせる

アイザックは淡いグレーの地に白いカード、irodas も白いカード、デライトは暗い地に写真タイル。**共通しているのは「地とカードの色が違う」こと。**

今の名鑑は背景が `#FAFAF8`、カードが白で、ほぼ同じ色だった。だから平坦に見えていた。v3で地を `#EFEFEB` まで落として差を作った。

### 4. 写真の面積が大きい

デライトは画面の半分以上が写真タイル。irodas は写真をずらして重ねる。GO ですら中央に大きく置く。

**ただしここは全部は真似できない。**名鑑は写真がない団体が大半なので、写真の面積に依存した設計は崩れる。→ §「取らなかったもの」へ。

## サイトごとに取ったもの

**irodas**
- 大きな英字見出し＋和文アイバー
- 黒いピル型ボタン、ラベル末尾のドット（`VIEW BUSINESS •`）
- 白いカードの薄い枠

**アイザック**
- 淡い地に白カードを浮かせる構造
- 上部に浮かぶ白いピル型ナビ
- `01 02 03` の連番リスト（→ v3では使っていない。§下記）

**デライト・ベンチャーズ**
- 大判の角丸タイルを並べる
- 写真を暗く沈め、上に白の太い和文を重ねる
- `⊙` 付きの小さなラベル（→ セクション見出しの記号として採用）

**GO**
- 細い横罫＋字間の広い和文アイバー
- 英字を主役サイズで組む

## 取らなかったもの と その理由

**デライトの「暗い地を全面に使う」**
かっこいいが、158団体を比べる名鑑には重い。暗い面はフッターだけにした。

**アイザックの「全面ベタの原色カード」**
赤いカードに白文字は強いが、**1団体のページに強い色面を敷くと、その団体の色を運営が上書きしてしまう。**団体の個性より運営のデザインが目立つ状態は、面談で見せる画面としてまずい。ジャンル色は写真がないときのタイルだけに限定した。

**アイザックの `01 02 03` の連番**
連番は順序に意味があるときだけ使える形。団体の情報に順序はないので使わない。

**irodas の写真コラージュ（ずらして重ねる）**
写真が3枚以上あって初めて成立する。1枚も持っていない団体が大半の今、この形を前提にできない。

**GO の背景に浮かぶ装飾の円**
意味のない図形は入れない。装飾を足すほど「よくあるサークルアプリ」に近づく。

## 参考サイトと決定的に違う点（ここが重要）

**参考の4つはすべて企業のブランドサイトで、ページ数が少なく、写真とコピーに予算がかかっている。**サークル名鑑は逆で、158ページあり、写真がなく、コピーは聞き取りで作る。

同じ作り方はできない。だから v3 では、**ブランドサイトの「文法」だけを借りて、主役を写真からデータに入れ替えた。**

### v3.1での結論

一度は「デライトが写真を置いている場所に週の時間割を置く」案にしたが、**採用しなかった。**情報を主役にすると、結局は資料に見える。

代わりに取ったのが、**参考サイトの一番強い共通点である「写真の面積」を、限界まで押し切る**という方針。写真を縦画面いっぱいに出して、ゆっくりズームで止める。スクロールすると写真が背後に沈んで、詳細が下から上がってくる。

写真がない団体は、同じ全画面をジャンル色のベタ塗りにして団体名を巨大に組む。**形が同じなので、写真の有無で設計が崩れない。**写真ゼロでも面談で見せられて、写真が集まるほど良くなる。

**「普通のサークルアプリ」との差は、1画面目で情報を見せないことで出る。**普通は開いた瞬間に情報が詰まっている。

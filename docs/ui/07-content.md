# 掲載情報の配置

作成済みの UI に、掲載データをどこへ出すかを定める。色・書体・角丸・影・余白・ヒーローの全画面表示・ズームイン・スクロールでシートが上がる動きは変えない。

新しい色・アイコン・カード種別は増やさない。追加項目は既存の行スタイルを使う。

---

## 掲載する15項目

1. キャッチコピー
2. 区分（大分類＋公式の所属区分）
3. 活動日
4. 活動頻度・活動場所
5. 掛け持ちの状況
6. 参加の緩さ
7. 先輩の呼び方
8. 年会費
9. 所属人数
10. 初心者の数
11. 男女比（合計10の比率）
12. この団体について
13. 代表からの一言
14. いま入れるかどうか
15. いつ聞いた情報か

この15項目から増やさない。

---

## 1. ヒーロー

ヒーロー内の文字は上から次の順にする。

```
運動系 ・ 体育会所属クラブ      11px / 字間0.14em / rgba(255,255,255,.75)
ハーフタイム                    34px / 太 / 白
フットサルサークル ハーフタイム  13px / rgba(255,255,255,.7)
```

区分は大分類と公式の所属区分を中黒でつなぐ。ジャンルはヒーローには出さない。

写真は `photos` を連番順に最大3枚使う。`photos` がなく `icon` だけある場合は、ヒーローにも `icon` を使う。どちらもなければジャンル色のベタ塗りに団体名を大きく組み、「No Image」「準備中」とは書かない。読み込み失敗時も同じジャンル色へ戻す。

一覧タイルと OGP は `icon` を使い、なければ `photos[0]` を使う。`icon` は幅400の1枚だけで、`@600` はない。`icon` と `photos[0]` が異なる場合、一覧から詳細への拡大は維持し、着地時にクロスフェードでヒーロー写真へ切り替える。

---

## 2. キャッチコピー

ヒーローの次、シートの一番上にカードへ入れず表示する。20px / 太 / 2行まで。団体名ではなく、団体の制約か他と違う点を書く。

---

## 3. 活動日カード

キャッチコピーの下、数字カードより上に、幅いっぱいの白いカードを1枚置く。枠・角丸・影・パディングは数字カードと同じものを使う。

```
┌────────────────────────────┐
│  活動日
│
│  月・木
│  ─────────────────────
│  活動頻度 週2回
│  活動場所 第2グラウンド
│  掛け持ちの状況 掛け持ちしている人がいる
│  参加の緩さ 来られる日だけでよい
│  先輩の呼び方 名字＋さん
└────────────────────────────┘
```

- `活動日` は数字カードのラベルと同じ 11px・字間0.14em・`ink-mid` で、カード上部に置く
- 曜日は30px・太字で、中黒でつなぐ
- 一覧で選んだ曜日と一致した曜日の文字だけ `match`（山吹）にする。それ以外に山吹を使わない
- 下段5行はすべて 13px・`ink-mid`・`line-height 1.7` の同じ行スタイルにする
- `multi_club` は可否へ変換せず、回答文字列と条件をそのまま表示する
- `days_undecided` は表示に使わない。活動日の表示ルールは空配列だけを見て従来どおりにする

活動日が空なら、30px のまま `活動日 未確認` と表示する。下段は値がない行も消さず、それぞれ `活動頻度 未確認` `活動場所 未確認` `掛け持ちの状況 未確認` `参加の緩さ 未確認` `先輩の呼び方 未確認` と表示する。

---

## 4. 数字カード

カードは4枚・2×2のままにする。

| 位置 | 値 | ラベル |
|---|---|---|
| 左上 | `¥3,000` | 年会費 |
| 右上 | `42` | 所属人数 |
| 左下 | `28` | 初心者出身 |
| 右下 | `6 : 4` | 男 : 女 |

### 4-1. 男女比

`male_ratio` を `genderRatio()` に通し、合計10の比率に丸める。1%でもいれば0にしない。0%は `女子のみ`、100%は `男子のみ` と表示する。

### 4-2. 未確認

- 数字カード内の未確認は `—`（emダッシュ・28px・`ink-mid`）とし、カードごと消さない
- 年会費の `0` は `¥0`。`null` の `—` と混同しない
- カード外の未確認は文字で `未確認` と表示する

---

## 5. 一覧カード

一覧カードの写真は `icon`、なければ `photos[0]` を使う。どちらもない場合や読み込みに失敗した場合はジャンル色タイルへ戻す。

年会費・所属人数・掛け持ちの状況は既存の1行に置く。掛け持ちの回答が長くてもカード幅を越えず、1行の末尾を省略記号にする。

「掛け持ち可」の絞り込みは置かない。`multi=1` の URL パラメータも発行・解釈せず、掛け持ち未確認を理由に一覧から団体を除外しない。

---

## 6. この団体について

既存の ABOUT カードをそのまま使う。3〜5行 / 15px / `line-height 1.85`。キャッチコピーと同じ内容を繰り返さない。

---

## 7. 代表からの一言

ABOUT の直後に、既存カードと同じ角丸・影・余白で表示する。本文は左に2pxの縦罫（`ink`）、左パディング14px、15px / `line-height 1.85`。署名は12px / `ink-mid` / 右揃えで、`代表（3年）` のように役職と学年だけを出し、個人名や顔写真は出さない。

本文が未確認でもブロックを消さず、`代表からの一言 未確認` と表示する。

---

## 8. いま入れるかどうか

次回新歓の日付と内容は掲載しない。既存位置に募集状態のバッジだけを残す。

| 状態 | 見た目 |
|---|---|
| `いつでも入れる` | `ink` 塗り・白文字・11px・角丸ピル |
| `4月のみ` | `ink` の1px枠・`ink` 文字・地は透明 |
| `募集していない` | `ink-mid` の1px枠・`ink-mid` 文字 |
| 未確認 | `ink-mid` の1px枠・`ink-mid` 文字で `未確認` |

山吹は使わない。

---

## 9. いつ聞いた情報か

フッターの掲載説明文の直後に、11px / `rgba(255,255,255,.6)` で `2026年9月 取材` の形にして表示する。

---

## 10. 載せないもの・変えないもの

活動時間、1回あたりの時間、年会費以外にかかる金、次回新歓の日付・内容、うち1年生は表示しない。`first_year_count` はデータとして保持するが画面には出さない。

歴史・実績・OB・顧問、SNSのフォロワー数、個人名・顔写真、口コミ・評価・ランキングは載せない。

SNSボタン、フッターの掲載説明と修正・取り下げリンク、ヒーローのズームインとカルーセル、スクロールでシートが立ち上がる動きは変えない。

---

## 11. 確認項目

1. ヒーローに大分類と公式の所属区分が中黒でつながっているか
2. 一覧・OGP は `icon` 優先、ヒーローは `photos` 最大3枚になっているか
3. 写真がない団体と読み込み失敗時がジャンル色タイルになるか
4. 活動日カードの下段5行が同じスタイルで、未確認の行も消えていないか
5. 数字カードが4枚・2×2のままで、男女比が `genderRatio()` の結果になっているか
6. 未確認の数字カードが `—` で、`¥0` と区別できるか
7. 代表からの一言に個人名・顔写真がないか
8. 募集状態のバッジが残り、次回新歓の日付・内容が消えているか
9. 「掛け持ち可」フィルターと `multi=1` がないか
10. 山吹が一致した曜日以外に使われていないか
11. 375px 幅で横スクロールがなく、一覧の長い掛け持ち回答が1行からはみ出さないか
12. ヒーロー・ズームイン・スクロール・カルーセルの動きが従来どおりか

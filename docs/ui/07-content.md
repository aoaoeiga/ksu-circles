# 追加プロンプト — 掲載情報の差し替え（UIは変えない）

用途: **いま出来上がっている団体ページに、このファイルをそのまま貼る。**
前提: `02-ui-spec-v3.2.md` で作った画面ができている状態。

---

## この指示の大前提

**いまのUIを変えない。**色・書体・角丸・影・余白・ヒーローの全画面写真・ズームイン・スクロールでシートが上がる動き、すべてそのまま。

変えるのは**中に入れる情報だけ**。新しい色や新しい形を持ち込まない。新しく足すブロックは §3 の活動日カードと §6 の代表からの一言の2つだけで、どちらも既存のカードと同じ枠・角丸・影を使い回す。それ以外は既存の要素に1行ずつ足す。

---

## 載せる情報（この14。増やさない）

1. キャッチコピー
2. 区分（運動系／文化系 など）
3. 活動日（独立したカードにする）
4. 活動時間と活動場所
5. **掛け持ちできるか**
6. 年会費
7. **年会費以外にかかる金**
8. 所属人数
9. 初心者の数
10. 男女比（合計10の比率）
11. この団体について（詳細）
12. 代表からの一言
13. いま入れるかどうか
14. いつ聞いた情報か

## 1. ヒーロー（全画面写真）— 区分を出す

いまの位置とサイズのまま、載せる文字だけ変える。上から順に。

```
運動系 ・ 体育会所属クラブ      ← 区分。11px / 字間0.14em / rgba(255,255,255,.75)
ハーフタイム                    ← 団体名。34px / 太 / 白
フットサルサークル ハーフタイム    ← 正式名称。13px / rgba(255,255,255,.7)
```

**区分は2段階を中黒でつなぐ。**

- 大分類: `運動系` `文化系` `その他`
- 公式の所属: `体育会所属クラブ` `文化団体連盟` `届出団体` `学生プロジェクトチーム` `委員会・その他`

新入生が知りたいのは前者、大学に持っていくときに効くのが後者。**両方出す。**ジャンル（球技・音楽など）はヒーローには出さない。

---

## 2. キャッチコピー

いまの「一言紹介」の位置と大きさをそのまま使う。**名前をキャッチコピーに変えるだけで、見た目は一切変えない。**

シートの一番上、カードに入れず地の上に直接。20px / 太 / 2行まで。

書き方だけ変える。**団体の制約か、他と違う点を1行で書く。**

- 良い例: `週1回、来られる日だけ来ればいい。事前連絡もいらない。`
- 悪い例: `明るく楽しいサークルです！`

---

## 3. 活動日カード ★独立した枠にする

キャッチコピーの下に、**幅いっぱいの白いカードを1枚新しく置く。**数字カードの上。

**枠・角丸・影・パディングは、いまの数字カードとまったく同じもの**を使う。新しい形を作らない。違うのは幅（2列ではなく1枚で全幅）だけ。

```
┌────────────────────────────┐
│  活動日                          │ ← 11px / 字間0.14em / ink-mid
│                                  │
│  月・木                           │ ← 30px / 太 / ink  ★カードの主役
│  18:00–20:00                     │ ← 等幅 / 16px / ink
│  ─────────────────────  │ ← 1px / rule
│  第2グラウンド ・ 掛け持ち できる    │ ← 13px / ink-mid
└────────────────────────────┘
```

- カード内の上にラベル `活動日`。数字カードのラベルと同じ書式（11px・字間0.14em・`ink-mid`）だが、**位置は上**にする。数字カードはラベルが下なので、そこだけ入れ替える
- 曜日はグリッドにしない。**中黒でつないだ文字**。`月・木` `月・水・金`
- 時刻は曜日の下に別行、等幅。曜日ごとに時間が違うときは `月 18:00–20:00 ／ 木 19:00–21:00`
- 場所と掛け持ちはカード下部に、`rule` の1px罫線で区切って1行。中黒でつなぐ
- 掛け持ちは `掛け持ち できる` / `掛け持ち できない` の2通りだけ。**必ず出す**

**このカードが数字カードより上にある理由。**新入生が最初に照合するのは自分の時間割で、大学公式サイトに横断して載っていない唯一のデータでもある。金額より先に来る。

**未確認の扱い**

- 曜日が分からない団体は、30pxのまま `活動日 未確認`（`ink-mid`）と出す。小さくして誤魔化さない。**カードが大きく空くことに意味がある。**面談中に「ここを埋めさせてください」と言える
- 時刻・場所・掛け持ちは、それぞれの行に `時間 未確認` `活動場所 未確認` `掛け持ち 未確認`

**一致したときの色**

一覧で曜日を絞ってからこのページに来たときだけ、**一致した曜日の文字だけ `match`（山吹）**にする。30pxで染まるので、ここが一番効く。それ以外で山吹を使わない。

**掛け持ちを省略しない理由。**一覧のフィルタに「掛け持ちできる団体だけ」があるので、ここに書いていないと、絞った結果の根拠がページ上に存在しないことになる。2つ目のサークルを探す人の一次条件でもある。

## 4. 数字（年会費・所属人数・初心者・男女比）と、別途かかる金

**カードは4枚・2×2のまま。**「うち1年生」を**男女比に差し替える**だけ。カード1枚の中身・書体・サイズ・角丸・影・並びは今のまま変えない。

| 位置 | 数値 | ラベル |
|---|---|---|
| 左上 | `¥3,000` | 年会費 |
| 右上 | `42` | 所属人数 |
| 左下 | `28` | 初心者出身 |
| 右下 | `6 : 4` | 男 : 女 |

### 4-1. 男女比の書き方 ★指定あり

**合計10の比率で出す。**

- 数値の位置に `6 : 4`（等幅28px）。**コロンだけ `ink-mid`** にして、左右の数字を読みやすくする
- ラベルは `男 : 女`
- 実数は出さない。人数は隣の「所属人数」カードにある

**丸め方のルール**（ここを決めておかないと団体ごとにブレる）

- 実数から比率を出して、**合計が必ず10になるように**丸める。四捨五入して合計が9や11になったら、人数の多い側で調整する
- **1人でもいれば0にしない。**56人中2人でも `9 : 1` と出す。`10 : 0` は、本当に0人のときだけ
- **本当に0人の団体**（女子のみ・男子のみ）は `10 : 0` と書かず、数値の位置に `女子のみ`（16px・`ink`）と1語で入れる

**分からないときは `—`（§4-3）。**「だいたい半々」と言われた概数を、確認済みの比率として書かない。


### 4-2. 別途かかる金 ★重要

3枚のカードの**すぐ下に、1行だけ**足す。12px / `ink-mid` / 左揃え。

```
別途：合宿費 年1回 ¥8,000 ／ 道着 初回のみ ¥9,000
```

複数あるときはスラッシュでつなぐ。**カードにしない。**行が増えるだけにする。

何もないときは `年会費のほかにかかる費用はありません。` と書く。**空欄にしない。**

**この行を省かない。**年会費だけ出して実は道着が9,000円、合宿が8,000円、月々のスタジオ代が1,000円、という団体がある。ここを隠すとサイト全体の信用が飛ぶ。金の話で嘘があると、他の数字も疑われる。

### 4-3. 数字の守りごと

- 未確認の項目は、数値の位置に **`—`（em ダッシュ・28px・`ink-mid`）** を入れる。**カードごと消さない**。文字で `未確認` と書くより、棒線のほうが数字の並びを崩さない
- 棒線は数字カードの中だけ。カードの外（活動日時・活動場所・掛け持ち）は文字で `未確認` と書く
- `¥0` は無料。`未確認` と必ず区別する。年会費が空欄の団体を無表示にすると、無料に見える
- **「初心者歓迎」と書かない。**全団体が歓迎を名乗るので情報がない。実数だけ出す

## 6. 代表からの一言 ★新しいブロック

ABOUT の直後に新しいブロックを1つ足す。

いまのカードと同じ見た目（同じ角丸・同じ影・同じ余白）にして、中だけ引用の組みにする。

```
┃ 上手い下手より、来られる日に来て
┃ くれる人がありがたいです。
┃ 試合に出たい人は出られます。
   代表（3年）
```

- 左に2pxの縦罫（`ink`）。パディング左14px
- 本文: 15px / `line-height 1.85` / `ink`。かぎ括弧は付けない（縦罫が引用を示す）
- 署名: 12px / `ink-mid` / 右揃え。**`代表（3年）` の形にして、個人名は入れない**
- 2〜3行に収める。長い話は §5 に入れる
- **新しい色・アイコン・顔写真を足さない。**顔写真を入れると、団体紹介ではなく人物紹介になる

このブロックは面談で効く。**代表が自分の言葉で載れる場所**があると、掲載の同意が取りやすくなる。

## 7. いま入れるかどうか

「次の新歓」のカードの**中の一番上**に、状態を示す小さなバッジを1つ置く。カードを増やさない。

| 状態 | 見た目 |
|---|---|
| `いつでも入れる` | `ink` 塗り・白文字・11px・角丸ピル |
| `4月のみ` | `ink` の1px枠・`ink` 文字・地は透明 |
| `募集していない` | `ink-mid` の1px枠・`ink-mid` 文字 |

**山吹は使わない。**

その下に、いまと同じ形で日付と内容を出す。

```
［ いつでも入れる ］
2026.10.02
体験練習会（運動できる服装・シューズ貸出あり）
［ 詳しく見る ］
```

日程が決まっていない団体は、バッジだけ出して `次の新歓は未定` `決まりしだい、このページに載せます。` と書く。

**日程と状態を別々に持つ理由。**新歓の日程が出せるのは一部の団体だけだが、「今からでも入れるか」は新入生の三大関心のひとつ。5月に見た人、9月に見た人にとっては、日程よりこちらが答えになる。

---

## 8. いつ聞いた情報か

フッターに1行足す。11px / `rgba(255,255,255,.6)`。

```
2026年9月 取材
```

掲載の説明文のすぐ下に置く。小さくてよい。

**この1行が名鑑の弱点をひとつ潰す。**この種のサイトは情報が腐って死ぬ。日付があるだけで「古いかもしれない」が「この時点では正しい」に変わる。面談でも効く。「来年また聞きに来ます」と言う根拠になるし、代表側も、今の情報だと分かる形で載るなら承諾しやすい。

---

## 9. 消すもの・載せないもの

**消す**

- 数字カードの「うち1年生」

**引き続き作らない**

- 明細リスト（場所・頻度・費用・掛け持ち・男女比を並べたもの）
- 週の時間割グリッド

**載せない**（聞かれても足さない）

- 歴史・実績・OB・顧問 — 大学公式にあり、新入生の判断材料にならない
- SNSのフォロワー数 — 団体間の格差がそのまま出る
- 個人名・顔写真

---

## 10. 変えないもの

SNSボタン、フッターの掲載説明と修正・取り下げリンク、ヒーローの動き、スクロールの動きは、いまのまま触らない。

## 11. できたか確認する

1. ヒーローに `運動系 ・ 体育会所属クラブ` の形で区分が出ているか
2. 活動日が**独立した白いカード**になっていて、枠・角丸・影が数字カードと同じか。曜日が30pxで主役になっているか
3. 数字カードが4枚・2×2のままで、右下が `6 : 4` の形（合計10）になっているか
4. 数字カードの下に「別途かかる金」の1行が出ているか。何もない団体でも空欄になっていないか
5. 代表からの一言が、他のカードと同じ見た目の中に縦罫で入っているか
6. 「次の新歓」カードの中に、募集状態のバッジが出ているか
7. フッターに取材時期の1行が出ているか
8. 個人名・顔写真が1つも出ていないか
9. 未確認の数字カードが `—` になっていて、カードごと消えていないか
10. `¥0` と `未確認` が別物として見えるか
11. 山吹が「一致した曜日」以外に使われていないか
12. **ヒーロー・ズームイン・スクロールの動きが、前とまったく同じか**
